02 / SÉCURITÉ & CONCEPTION

Bâti pour la stabilité. Isolé par défaut.

Chaque extension s'exécute dans une bulle étanche sans accès arbitraire à vos disques ni aux processus système Windows.

memory

Plafond Mémoire Strict

Chaque extension est plafonnée à 64 Mo de RAM allouée. Tout dépassement ou fuite mémoire est stoppé net sans altérer la fluidité du jeu.

Limite : 64.0 Mo fixes
fence

Permissions Déclaratives

Les plugins déclarent leurs besoins dans le manifest. Un plugin Discord ne peut pas lire votre disque dur, et un driver LED ne peut pas accéder à internet.

Isolation : Appels WASI filtrés

Communication Zéro-Copie

La télémétrie et les boutons transitent via des ring buffers en mémoire partagée. La latence mesurée reste inférieure à 0.1 milliseconde.

Latence : < 0.1 ms mesurée

PROCESSUS DE PUBLICATION

Comment publier votre propre plugin ?

De l'écriture du premier hook à la distribution mondiale auprès des utilisateurs KaïroOS.

01

Développez localement

Clonez le modèle officiel kairo-plugin-template et écrivez vos fonctions en Rust ou TypeScript.

SDK v1.0 compatible
02

Testez en direct

Déposez votre build dans ~/.kairo/plugins/dev/ et testez avec le rechargement à chaud (Hot Reload).

Logs terminal instantanés
03

Soumettez une PR

Ouvrez une Pull Request sur le dépôt du store KaïroOS avec votre manifest vérifié et vos métadonnées complètes.

Revue communautaire
04

Validation & Déploiement

Dès validation par la CI de sécurité sandboxée, votre extension devient téléchargeable en 1 clic par toute la communauté !

Disponible immédiatement
