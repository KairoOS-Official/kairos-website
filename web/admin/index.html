Sauvegarde, Chargement & Réinitialisation Complète

Gestion sécurisée des données de la plateforme conforme au RGPD. La sauvegarde exclut automatiquement tout élément périmé, le chargement purge les données expirées, et la réinitialisation efface l'ensemble des données dynamiques sans toucher à vos identifiants administrateurs.

download 1. Exporter la Sauvegarde

Génère et télécharge une archive JSON intégrale. Ne récupère pas les éléments expirés selon les durées légales RGPD.

upload_file 2. Charger une Sauvegarde

Sélectionne un fichier JSON pour restaurer les données. Supprime immédiatement tous les éléments qui auraient dû être supprimés par le temps RGPD.

delete_forever 3. Tout Supprimer

Efface absolument toutes les données dynamiques (analytics, clics, votes, idées, recours, logs, IPs). Vos comptes d'accès administrateurs sont préservés.
