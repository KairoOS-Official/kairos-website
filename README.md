# 🕹️ KaïroOS — Site Web Officiel

Site de présentation de KaïroOS, le frontend d'arcade moderne et 100% personnalisable.

---

## 📦 Structure

```
kairos-website/
├── index.html          ← Page d'accueil
├── css/
│   └── style.css       ← Styles globaux
├── js/
│   └── main.js         ← Interactions (menu, animations)
├── assets/
│   ├── logo.png        ← Logo KaïroOS
│   ├── favicon.ico     ← Favicon
│   └── images/         ← Screenshots, illustrations
├── pages/
│   ├── features.html   ← Fonctionnalités
│   ├── plugins.html    ← Système de plugins
│   ├── themes.html     ← Système de thèmes
│   ├── download.html   ← Téléchargement
│   └── docs.html       ← Documentation
└── README.md
```

---

## 🎨 Design

- **Style** : Dark mode arcade, néon, rétro-futuriste
- **Palette** : Fond sombre (#0b0f19), accent rose (#f43f5e), secondaire bleu (#38bdf8)
- **Polices** : Outfit (texte), Press Start 2P (accents arcade)
- **Ambiance** : Scanlines CRT subtils, lueurs néon, animations fluides
