Conçu pour les Développeurs & Makers

Une flexibilité sans compromis technique.

Fini les interfaces figées ou les fichiers binaires opaques. KairoOS utilise les standards modernes du web empaquetés en micro-binaire C++/WebView ultra-rapide.

view_in_ar

Composants React 19 & Tailwind

Créez des agencements sur-mesure avec l'écosystème React standard. Profitez d'animations pilotées à 100% par le GPU pour un affichage stable sur téléviseurs 120Hz et moniteurs CRT 15kHz.

Variables CSS & Thèmes JSON

Ajustez la typographie, les courbures de coins, la force des scanlines ou les ombres portées dans un simple fichier theme.json sans jamais avoir besoin de compiler le moindre code.

data_object STRUCTURE DE CONFIGURATION STANDARD

Configurez votre univers en quelques clés JSON.

Un thème KairoOS est composé d'un descripteur de métadonnées, d'une feuille de jetons CSS et de modèles de vues. Les jaquettes et captures d'écran de vos ROMs s'injectent automatiquement dans les slots correspondants.

check_circle

Hot Reloading : Enregistrez votre fichier dans themes/custom-theme/ pour voir vos modifications immédiatement.

check_circle

Gestion du son d'ambiance : Prise en charge des jingles WAV/OGG pour les mouvements de curseur et le lancement de jeux.
